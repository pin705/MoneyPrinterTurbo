# Internationalization (i18n)

The app is **Vietnamese-first**. Market = Vietnam (VND, SePay).

- **Natural keys.** English source strings ARE the i18n keys. `t("Generate Video")` →
  looked up in `apps/web/src/i18n/vi.ts`; missing keys fall back to the English key.
- **Default language is `vi`** (`apps/web/src/i18n/index.ts`: `lng: stored ?? "vi"`).
- **Every new user-facing string** must get a VI entry in `vi.ts`. Don't ship English-only UI.
- Keep interpolation tokens intact: `t("Planned for {{phase}}", { phase })`.
- Shared data (e.g. `CONTENT_TEMPLATES` in `@mpt/shared`) uses English `titleKey`/`descKey`
  that resolve through `t()` — add the VI translations in `vi.ts`.
- **Landing** (`apps/landing/`) has its own bilingual copy in `src/i18n/landing.ts`
  (full `en` + `vi` objects). VN is the default at `/`, English at `/en/`.
- **Tests** pin English: e2e sets `localStorage["mpt-lang"] = "en"` so label-based
  assertions stay deterministic. If you add label-based tests, do the same.
- **Render scripts/voices**: script language is a separate param (`video_language`),
  independent of UI language. Subtitle font must cover the script language
  (vi → `BeVietnamPro-Bold.ttf`; CJK fonts lack Vietnamese diacritics → tofu boxes).
